# 画面見本（チームチャットアプリ）

静的HTML 10枚です。**ファイルをブラウザにドラッグするだけで表示されます**（サーバもビルドも不要／JavaScriptなし／インターネットに繋がっていなくても表示されます）。

まず `index.html`（画面カタログ）を開いてください。そこから全画面へ移動できます。

| ファイル | 画面 |
|:--|:--|
| `index.html` | 画面カタログ（入口） |
| `channel-show.html` | チャンネル（メッセージ一覧） |
| `channels.html` | チャンネル一覧 |
| `thread.html` | スレッド（チャンネルの右側に開くパネル） |
| `search.html` | 検索結果（0件の見本も同じページに） |
| `members.html` | メンバー管理（プライベートチャンネル） |
| `channel-new.html` | チャンネルを作る |
| `channel-edit.html` | チャンネルを編集する／削除の確認 |
| `login.html` | ログイン |
| `register.html` | 新規登録 |

- 色・字・余白・状態の決まりは `design-guide.md` にまとめてあります
- スタイルは `styles.css` の1枚だけです
- 押しても動きません。切り替えて見せる状態（エラー・確認・0件・ホバー中の操作）は、**静的に開いた状態**で描くか、同じページに並べています
- `※` で始まる灰色の文は**見本のための注記**です。アプリの画面に出す文言ではありません

> ⚠️ **この見本にJavaScriptを使っていないのは、見本だからです。**アプリでJavaScriptを使うかどうかは、あなたが設計で決めることです。この見本は、その判断を縛るものではありません。

**ピクセル単位で同じにする必要はありません。**合わせるのは、並び・項目・言葉づかい・状態の見せ方です。
