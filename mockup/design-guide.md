# デザイン指定書｜チームチャットアプリ

CSSにそのまま書ける値です。値はすべて `styles.css` の先頭に CSS変数として定義してあるので、モックアップを読むときも実装するときも、この表と `styles.css` を突き合わせられます。Webフォント・外部CDN・画像ファイルは使いません。

---

## 2. 文字

```css
font-family: -apple-system, BlinkMacSystemFont, "Hiragino Kaku Gothic ProN",
  "Hiragino Sans", "Yu Gothic UI", "Yu Gothic", Meiryo, "Segoe UI",
  system-ui, sans-serif;
```

Windows は Yu Gothic UI / Meiryo、macOS は Hiragino が当たります。Webフォントは読み込みません。

| 用途 | クラス | サイズ | 太さ | 行間 | 使いどころ |
|:--|:--|:--|:--|:--|:--|
| 大見出し | `.h-display` | 24px | 700 | 1.35 | ログイン／新規登録のカード見出し |
| 画面タイトル | `.h-title` | 20px | 700 | 1.35 | 画面名・チャンネル名 |
| 節見出し | `.h-heading` | 16px | 700 | 1.35 | カードの中の見出し |
| 本文 | `.t-body` | 14px | 400 | 1.8 | メッセージ本文・説明文 |
| ラベル | `.t-label` | 13px | 500 | 1.55 | フォームのラベル・ボタン・投稿者名 |
| 補足 | `.t-caption` | 12px | 400 | 1.55 | 日時・件数・チャンネル説明・エラー文 |
| グループ見出し | `.t-group` | 11px | 700 | 1.55（字間 .06em） | サイドバーの「チャンネル」 |

- 日時と文字数は `font-variant-numeric: tabular-nums`。
- 日時の表記は `2026/08/17 14:32` に固定。
- 最小サイズは 11px（グループ見出しのみ）。本文は 14px を下回らない。

## 3. 余白と大きさ

**余白の刻み**: 4px の倍数 — `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`
使い分け: 要素間 8・12、面の内側 16・20、カードの内側 20、画面の外周 32、節と節の間 32〜48。

| 用途 | 変数 | 値 |
|:--|:--|:--|
| 角丸（小） | `--r-sm` | `4px`（バッジ・ロゴの記号） |
| 角丸（標準） | `--r-md` | `6px`（ボタン・入力欄・サイドバーの行） |
| 角丸（大） | `--r-lg` | `8px`（カード・パネル・投稿欄・空状態） |
| 角丸（円） | `--r-full` | `999px`（**アバターのみ**） |
| サイドバー幅 | `--sidebar-w` | `260px`（固定） |
| 上部バーの高さ | `--topbar-h` | `52px`（固定） |
| スレッドパネル幅 | `--thread-w` | `400px`（固定） |
| 本文の最大幅 | `--content-max` | `880px` |
| フォームカード幅 | `--form-max` | `420px`（ログイン・新規登録） |
| ボタン／入力欄の高さ | `--ctl-h` | `36px` |
| 小 | `--ctl-h-sm` | `28px` |
| 大 | `--ctl-h-lg` | `44px`（ログインの主ボタン。横幅いっぱい） |

画面の最小幅は 1280px。レスポンシブ対応はしません。

**影**

| 変数 | 値 | 使いどころ |
|:--|:--|:--|
| `--sh-1` | `0 1px 2px rgba(27,32,40,.06)` | カード・ボタン |
| `--sh-2` | `0 1px 3px rgba(27,32,40,.08), 0 4px 12px rgba(27,32,40,.06)` | メッセージのホバー操作 |
| `--sh-3` | `0 8px 28px rgba(27,32,40,.16)` | ダイアログ |

## 4. 状態の決まり

| 状態 | 見せ方 |
|:--|:--|
| **入力エラー** | 入力欄の枠 `#B3261E`・地 `#FCEFEE`、欄の下に 12px の赤文字。文頭に赤い丸の `!` を置く。フォーカスリングも赤（`rgba(179,38,30,.2)`）。エラー文は1文・句点なし。例:「チャンネル名を入力してください」 |
| **押せない（無効）** | 地 `#EBEEF2`・枠 `#DDE1E6`・文字 `#9AA3AD`・影なし・`cursor: not-allowed`。理由があるときは横に 12px の補足を添える（例:「作成者は外せません」）。非表示にはしない |
| **選択中（サイドバー）** | 地 `#234B80`・文字 `#FFFFFF`・太さ500。記号（`#`／鍵）は `#CFE0F3` |
| **選択中（選択肢）** | 枠 `#2B5C9B`＋外側に 1px の同色・地 `#EEF3F9` |
| **ホバー** | 明るい面: 地を `#F4F6F8` に。暗色面: 地を `#2E3742` に。塗りボタン: 1段暗い色に。透明度は変えない |
| **フォーカス** | 枠を `#2B5C9B` にし `0 0 0 3px rgba(43,92,155,.35)` |
| **空・0件** | 破線 1px `#C4CBD3`・角丸 8px・地 `#FAFBFC`・中央揃え・上下 40px。見出し 16px/700 に事実、その下 13px `#6B7580` に次の一手 |
| **編集済み** | 本文の末尾に半角スペースを空けて 12px `#6B7580` で `編集済み`。本文の体裁は変えない |
| **削除されました** | 本文を出さず、破線 1px `#C4CBD3`・角丸 6px・地 `#FAFBFC`・高さ 24px の枠に 12px `#6B7580` で `このメッセージは削除されました`。投稿者名と日時は残す。**返信は残るので、返信件数の表示も消さない** |
| **返信あり** | 本文の下に 12px のリンク `返信3件`。ホバーで地 `#EEF3F9`＋枠 `#B0C7E0` |
| **メッセージのホバー操作** | 行の右上に白い小さな枠（角丸 6px・`--sh-2`）で 返信／編集／削除 の28pxアイコンボタン。自分のメッセージにだけ編集・削除を出す |
| **編集中（メッセージ）** | 本文があった場所が入力欄に変わる。まわりのメッセージはそのまま。入力欄の下に「保存」と「やめる」を横並びに置き、「保存」だけ塗り |
| **文字数** | 入力欄の下（右）に 12px `#6B7580`。**入力に追随させるなら** `248 / 1,000 文字`、上限超過は `#B3261E`＋太さ500。**追随させないなら** `1,000文字まで` の目安表示にする（どちらにするかは実装の判断） |
| **削除の確認** | 赤い枠のカードに、対象名を含む問い・影響範囲の件数・「この操作は取り消せません」・確認入力欄。確定ボタンだけ塗りの赤（`#B3261E`） |

## 5. この見本の約束

- **ピクセル単位で一致させる必要はありません。**合わせるのは、並び・項目・言葉づかい・状態の見せ方です
- 画面に出すアプリ名は「**チームチャットアプリ**」で統一します
- 見本の中で `※` で始まる灰色の文は、**見本のための注記**です。アプリの画面に出す文言ではありません
- **この見本はJavaScriptを使っていませんが、それは見本だからです。**アプリ側で使うかどうかは設計の判断です。たとえば文字数の表示は、入力に追随させるか、静的な目安にとどめるかを自分で決めます
