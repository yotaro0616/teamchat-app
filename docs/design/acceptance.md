# 受け入れ条件とテスト観点

このファイルは `docs/spec.md`、`mockup/`、`docs/design/`（`features.md`・`questions.md`・`screens.md`・`data.md`・`permissions-api.md`・`behavior.md`）の一式を根拠にしている。ここに無いことは想像で足していない。

**前提**: すべての受け入れ条件・テスト観点は、spec §5-4 の初期データ（アカウント3つ・チャンネル4つ・メッセージ一式）が投入された状態を前提にする。初期データそのものが正しく入っているかどうかは、個々の受け入れ条件（例えば `sato@example.com` でログインできること自体）の実行可能性が証拠になるため、別枠のAC番号は立てていない。

**実装単位と番号**: 認証(1)／チャンネル(2)／メンバー管理(3)／メッセージ(4)／スレッド(5)／検索(6)／公開API(7)。受け入れ条件は `AC-<単位番号>-<連番>`。

**線引き**: 受け入れ条件は人が手でブラウザを1行ずつ操作して確かめるものなので、実装単位ごとに2〜4行に絞った。入力の境界値や異常系の組み合わせなど、網羅的に確かめたい点はすべてテスト観点（2章）に置き、受け入れ条件には含めていない。

## 1. 受け入れ条件

### 1-1. 認証

| ID | 受け入れ条件 |
|:--|:--|
| AC-1-1 | 新規登録フォームに表示名・メールアドレス・8文字以上のパスワードを入力して登録すると、アカウントが作成され、ログイン画面に遷移する |
| AC-1-2 | 佐藤太郎のアカウント（`sato@example.com` / `password`）でログインすると、チャンネル一覧画面が表示される |
| AC-1-3 | ログイン中にログアウトすると、ログイン画面に戻り、その後チャンネル一覧のURLに直接アクセスするとログイン画面に送り返される |
| AC-1-4 | 登録済みのメールアドレスに誤ったパスワードでログインしようとすると、「メールアドレスまたはパスワードが正しくありません」と表示され、ログインできない |

### 1-2. チャンネル

| ID | 受け入れ条件 |
|:--|:--|
| AC-2-1 | チャンネル一覧画面で「チャンネルを作る」からチャンネル名・説明・公開範囲を入力して作成すると、一覧に新しいチャンネルが表示され、作成したそのチャンネルの画面が開く |
| AC-2-2 | AC-2-1で作成したチャンネルの名前と説明を編集して保存すると、チャンネル画面に変更後の内容が表示される |
| AC-2-3 | AC-2-2で編集したチャンネルの削除確認画面にチャンネル名を正しく入力して削除すると、そのチャンネルは一覧から消える |
| AC-2-4 | 高橋健（採用プロジェクトのメンバーではない）でログインすると、チャンネル一覧にもサイドバーにも「採用プロジェクト」は表示されない |

AC-2-2・AC-2-3はAC-2-1で新しく作ったチャンネルに対して行う（初期データの「開発」を編集・削除すると、4章以降のACが前提にしている初期データが崩れるため）。

### 1-3. メンバー管理

| ID | 受け入れ条件 |
|:--|:--|
| AC-3-1 | 佐藤太郎で「採用プロジェクト」のメンバー管理画面を開き、高橋健を表示名で検索して追加すると、メンバー一覧に高橋健が追加される |
| AC-3-2 | 続けて高橋健をメンバーから外すと、メンバー一覧から消える |
| AC-3-3 | 佐藤太郎で自分（作成者）を外そうとすると、「外す」ボタンが押せない状態になっている |
| AC-3-4 | 鈴木花子（採用プロジェクトのメンバーだが作成者ではない）でメンバー管理画面のURLに直接アクセスすると、開けない |

### 1-4. メッセージ

| ID | 受け入れ条件 |
|:--|:--|
| AC-4-1 | 「開発」チャンネルを開いてメッセージを投稿すると、一覧の一番下に投稿者名・日時付きで表示される |
| AC-4-2 | 自分が投稿したメッセージを編集して保存すると、本文が変わり、末尾に「編集済み」の印が付く |
| AC-4-3 | 自分が投稿したメッセージを削除すると、その場所が「このメッセージは削除されました」に変わる |
| AC-4-4 | 他の人が投稿したメッセージには、編集・削除の操作アイコンが表示されない |

### 1-5. スレッド

| ID | 受け入れ条件 |
|:--|:--|
| AC-5-1 | 返信が3件以上付いた初期データのメッセージを開くと、「返信N件」の件数と一致する数の返信がスレッドパネルに表示される |
| AC-5-2 | スレッドパネルから返信を投稿すると、元メッセージの「返信N件」の件数が1つ増える |
| AC-5-3 | 返信が付いたメッセージを本人が削除しても、「返信N件」の件数とスレッドの中身はそのまま残る |

### 1-6. 検索

| ID | 受け入れ条件 |
|:--|:--|
| AC-6-1 | 「開発」チャンネルのメッセージに含まれるキーワードで検索すると、そのメッセージがチャンネル名・投稿者・日時付きで結果に出る |
| AC-6-2 | 一致するメッセージが無いキーワードで検索すると、「〜に一致するメッセージはありません」と表示される |
| AC-6-3 | 高橋健（採用プロジェクトのメンバーではない）でログインし、採用プロジェクトのメッセージに含まれる言葉で検索しても、結果に出てこない |

### 1-7. 公開API

| ID | 受け入れ条件 |
|:--|:--|
| AC-7-1 | ログインしていない状態でブラウザから `/api/channels` を開くと、「全体連絡」「開発」「雑談」が公開チャンネルとしてJSONで返る |
| AC-7-2 | ログインしていない状態で「開発」チャンネルの `/api/channels/{id}/messages` を開くと、「開発」チャンネルのメッセージ一覧がJSONで返る |
| AC-7-3 | 「採用プロジェクト」のチャンネルIDで `/api/channels/{id}/messages` を開くと、404が返り、チャンネル名などの情報が含まれない |
